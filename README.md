# 🩺 Diabetes Exploratory Data Analysis (EDA)

Bu proje, Python ve veri bilimi kütüphaneleri (`Pandas`, `Matplotlib`, `Seaborn`) kullanılarak **Diyabet Veri Seti** üzerinde yapılan keşifçi veri analizi (EDA) çalışmasını içermektedir.

## 🚀 Projede Yapılan Adımlar
1. **Veri Yükleme ve İnceleme:** Veri setinin okunması ve ilk 5 satırın incelenmesi.
2. **Boyut Analizi:** Satır ve sütun sayılarının tespiti (`768 satır, 9 sütun`)
3. **Veri Tipleri ve Bilgiler:** `df.info()` kullanılarak değişkenlerin türlerinin kontrol edilmesi
4. **İstatistiksel Özet:** `df.describe()` ile ortalama, standart sapma, çeyreklik dilimler (min, max, %25, %50, %75) ve dağılımların incelenmesi
5. **Eksik Değer Kontrolü:** Null/eksik verilerin tespiti.
6. **Görselleştirme:** `Matplotlib` kullanılarak hastaların (Diabetic / Not Diabetic) oranlarını gösteren pasta grafiği (`Pie Chart`) oluşturulması.

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler
* Python  3.13.9
* Pandas (Veri manipülasyonu)
* NumPy (Sayısal işlemler)
* Matplotlib & Seaborn (Veri görselleştirme)
